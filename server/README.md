# PixiPod Leads API

1. Скопируйте `.env.example` в `.env`.
2. Создайте пароль приложения для ящика Mail.ru и сохраните его как `MAIL_PASSWORD`.
3. При необходимости замените параметры SMTP и адрес получателя.
4. Запустите API командой `npm run start:dev`.

Фронтенд отправляет `POST /api/leads`; Vite проксирует этот маршрут на порт `3001`.
